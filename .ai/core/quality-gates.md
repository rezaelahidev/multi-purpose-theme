# Quality Gates

## Gate A — Product scope
Human approval required for product brief, target users, and MVP scope.

## Gate B — Architecture
Human approval required for architecture baseline and any material ADR change.

## Gate C — Design system
Human approval required before the design system is treated as the implementation baseline.

## Gate D — Implementation review
Automated checks and independent review required. Human review required for material
changes to public behavior, data handling, or compatibility commitments.

## Gate E — Release
Human approval required. No agent may publish or deploy autonomously under v0.1.

Every gate must record: decision, reviewer, date, evidence/artifacts, and follow-up actions.
