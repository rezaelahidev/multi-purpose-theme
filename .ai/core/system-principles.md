# System Principles

1. **Repository is truth:** durable facts and decisions belong in Git.
2. **One canonical definition:** shared agent and workflow intent has one source.
3. **Explicit contracts:** inputs, outputs, permissions, and acceptance criteria are declared.
4. **Artifact-driven work:** handoffs reference files, not summaries alone.
5. **Progressive context:** load only context relevant to the current task.
6. **Human governance:** approval gates cannot be bypassed by another agent.
7. **Least privilege:** grant only the tools and file access required.
8. **Evidence over assertion:** report evidence and uncertainty.
9. **Reversible decisions:** significant architectural choices use ADRs.
10. **Adapter thinness:** runtime configuration translates; it does not own core logic.
11. **No silent degradation:** unsupported runtime capabilities are disclosed.
12. **Small, reviewable changes:** prefer bounded tasks and focused diffs.
